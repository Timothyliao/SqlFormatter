## 1. 产品概述

SQL Formatter 是一个运行于浏览器端的纯前端 SQL 格式化工具。用户无需安装任何软件，打开页面即可使用。工具在左侧提供基于 CodeMirror 6 的代码编辑器接收 SQL 输入，在右侧实时输出格式化后的带语法高亮结果，并支持一键复制到剪贴板。

**核心价值**：
- 零服务器依赖，SQL 数据不离开本地浏览器
- 实时响应，输入即格式化
- 专业代码编辑体验（行号、括号匹配、语法高亮）
- 支持多种 SQL 方言与丰富的自定义格式化规则
- 可拖拽调整左右分屏宽度，适应不同工作习惯
- 明亮/暗黑双主题，自动跟随系统偏好
- 格式化结果行号显示，便于定位
- 多文档管理（最多 5 个），刷新后自动恢复
- 可调节编辑器与预览字体大小
- 设置项收纳于弹窗，界面更简洁
- Ctrl+S 快捷保存，标签页显示未保存状态
- 多语句折叠/展开，快速定位目标语句

## 3. 核心功能

### 3.1 CodeMirror 编辑器

左侧输入区使用 CodeMirror 6 替代普通文本框，提供专业代码编辑体验：

- **行号** — 每行左侧显示行号，便于定位
- **括号匹配** — 光标靠近括号时高亮显示匹配的另一半
- **SQL 语法高亮** — 输入区同步高亮关键字、字符串、注释等
- **撤销/重做** — 支持 Ctrl+Z / Ctrl+Y 操作历史
- **当前行高亮** — 光标所在行有淡色背景，便于追踪位置

### 3.2 实时格式化

用户在编辑器中输入或粘贴 SQL 后，右侧预览区自动更新格式化结果，无需手动点击按钮。

- 防抖延迟：≤ 300ms（避免高频输入时的性能抖动）
- 输入为空时：预览区显示占位提示文字
- 格式化失败时：预览区显示原始文本，顶部显示错误提示横幅

### 3.3 语法高亮预览

格式化结果以彩色语法高亮形式展示，不同 Token 类别使用不同颜色，暗黑/明亮主题下均满足 WCAG AA 对比度标准：

| Token 类别 | 暗黑主题颜色 | 明亮主题颜色 | 示例 |
|------------|-------------|-------------|------|
| 关键字 | 紫色（#cba6f7） | 紫色（#8839ef） | `SELECT`, `FROM`, `WHERE` |
| 字符串字面量 | 绿色（#a6e3a1） | 绿色（#40a02b） | `'active'` |
| 数字字面量 | 橙色（#fab387） | 橙色（#fe640b） | `42`, `3.14` |
| 标识符/变量 | 青色（#89dceb） | 青色（#04a5e5） | 表名、列名 |
| 运算符/标点 | 蓝色（#89b4fa） | 蓝色（#1e66f5） | `=`, `>`, `(`, `)` |
| 注释 | 灰色（#6c7086，斜体） | 灰色（#8c8fa1，斜体） | `-- 注释` |

### 3.4 明亮/暗黑主题切换（v1.2.0 新增）

页面右上角提供主题切换按钮（☀️ / 🌙）：

- 默认跟随操作系统偏好（`prefers-color-scheme`）
- 切换后持久化到 `localStorage`，下次访问自动恢复
- 切换同步更新：CSS 变量、CodeMirror 编辑器主题、语法高亮颜色
- 暗黑主题：Catppuccin Mocha 调色板
- 明亮主题：Catppuccin Latte 调色板

### 3.5 格式化结果行号（v1.2.0 新增）

预览面板左侧显示行号栏，与编辑器行号风格一致：

- 行号与代码内容同步滚动
- 行号区域不可选中（`user-select: none`），不影响复制操作
- 行号颜色使用低对比度的 muted 色，不干扰代码阅读

### 3.6 多文档管理（v1.4.0 重构，v1.5.0 增强）

顶部文档标签栏支持同时管理多份 SQL 文档：

- 最多 5 个文档，点击 `+` 新建，文档编号单调递增不重复
- 点击标签切换文档，切换前自动保存当前文档的未提交改动
- 标签有未保存改动时显示蓝色小圆点（dirty 指示）
- 双击标签名或点击铅笔图标可重命名（最多 30 字符）
- 只剩一个文档时删除按钮禁用
- 所有文档持久化到 `localStorage`，刷新后自动恢复
- 单条 SQL 上限 200KB，超出自动截断

### 3.7 保存文档（v1.4.0 新增，v1.5.0 增强）

- 编辑停止 1s 后自动保存到 localStorage
- 左侧面板「保存」按钮或 `Ctrl+S`（Mac: `Cmd+S`）立即保存
- 保存按钮显示状态反馈：保存中… → 已保存 ✓ / 保存失败

### 3.8 多 SQL 方言支持

支持以下三种 SQL 方言，通过顶部下拉菜单切换（始终显示在 Header 中）：

| 方言 | 说明 |
|------|------|
| PostgreSQL（默认） | 适用于 PostgreSQL 数据库 |
| MySQL | 适用于 MySQL / MariaDB |
| SQLite | 适用于 SQLite 数据库 |

### 3.9 关键字大小写

控制 SQL 关键字的大小写形式：

| 选项 | 效果 |
|------|------|
| 大写（默认） | `SELECT`, `FROM`, `WHERE` |
| 小写 | `select`, `from`, `where` |
| 保留 | 保持输入时的原始大小写 |

### 3.10 逗号位置

控制多列列表中逗号的位置（行尾/行首）。

### 3.11 语句间距

控制多条 SQL 语句之间的空行数量（1 行 / 2 行）。

### 3.12 缩进宽度配置

支持 2 空格（默认）或 4 空格缩进。

### 3.13 IN 子句值分组

对 `IN (...)` 子句按用户设定的「每行值数」进行分组换行，默认每行 3 个值，可配置范围 1–100。

### 3.16 语句折叠（v1.6.0 新增）

格式化包含多条 SQL 语句的输入时，预览区行号列显示折叠控件：

- 鼠标移入行号区，所有可折叠语句的 `▼`/`▶` 图标同时显示
- **展开态**：`▼` 图标，完整高亮内容可见
- **折叠态**：`▶` 图标，显示第一个 SQL 关键字行的摘要文本（超 80 字符截断 + `…`）
- **注释行始终可见**：折叠时头部注释行保留显示，不被隐藏
- 单条语句、纯注释块不显示折叠图标
- 折叠后行号跳跃体现折叠范围（如 1, 2, 3, **10**, 11…）
- 折叠状态不影响「复制」按钮——始终复制完整 SQL

**快捷键**（显示在预览区标题栏）：

| 快捷键 | 操作 |
|--------|------|
| `Ctrl+Shift+[` | 折叠全部语句 |
| `Ctrl+Shift+]` | 展开全部语句 |

### 3.14 可拖拽分屏宽度

桌面端（≥ 768px）可通过拖拽中间分隔线调整左右面板宽度比例（20%–80%），支持键盘微调。

### 3.15 一键复制

预览面板右上角「复制」按钮，将格式化后的纯文本写入系统剪贴板。

### 3.17 SQL 进化论（v1.7.0 新增）

右下角常驻一个可拖拽的「生命体」，随 SQL 复杂度实时进化：

- 7 级进化：🦠 原始汤 → 🐛 虫子 → 🐟 鱼 → 🦎 爬行动物 → 🦕 恐龙 → 🧠 大脑 → 👾 未知生命
- 评分维度：行数、JOIN、子查询、CTE、窗口函数、UNION
- 进化时有放大旋转动画 + 进化宣言气泡
- 可拖拽到屏幕任意边缘吸附，位置持久化
- Hover 显示详细评分和进度条

### 3.18 彩蛋系统（v1.7.0 新增）

特定 SQL 输入触发隐藏彩蛋效果，共 8 个可收集：

| 触发条件 | 效果 |
|----------|------|
| `DROP TABLE` | 屏幕抖动 + 终端气泡倒计时拦截 |
| `DELETE FROM` 无 WHERE | 预览区文字蒸发消失再恢复 |
| `TRUNCATE` | 终端气泡「清空宇宙」 |
| `SELECT *` | 气泡「真的需要所有列吗？」 |
| `SELECT 1` | 预览区数字短暂变成 42 |
| `SELECT NULL` | 终端气泡「虚无即是答案」 |
| 只写 `;` | 气泡「史上最简洁的 SQL」 |
| SQL 超 500 行 | 彩带从天而降 |

- 生命体右上角 `✦` 图标打开彩蛋图鉴，显示收集进度
- 所有效果通过气泡展示，不打断操作
- 由 FunMode 开关控制，可随时关闭

## 6. 技术架构

### 6.1 整体架构（v2.0.0 Vue 版本）

```
┌──────────────────────────────────────────────────────────────────────────┐
│                              Vue 组件层                                   │
│  InputPanel.vue │ ConfigPanel.vue │ PreviewPanel.vue │ CopyButton.vue     │
│  ThemeToggle.vue │ HistoryPanel.vue │ ResizableDivider.vue                │
│  fun/EvolutionWidget.vue │ fun/EggBook.vue                                │
└──────────────────────────┬───────────────────────────────────────────────┘
                           │ 读写 Pinia Store
                           ▼
┌──────────────────────────────────────────────────────────────────────────┐
│                           Pinia Store 层                                  │
│  formatterStore │ historyStore │ themeStore │ uiStore                     │
└──────┬────────────────────────────────────────────┬──────────────────────┘
       │                                            │
       ▼                                            ▼
┌─────────────────┐                    ┌──────────────────────────┐
│  Formatter      │                    │  Highlighter             │
│  (sql-formatter)│                    │  (highlight.js)          │
└─────────────────┘                    └──────────────────────────┘
```

### 6.2 核心模块

#### formatterStore
管理 SQL 内容、格式化配置、输出 HTML、错误信息。使用 `watchDebounced([sql, config], 250ms)` 触发格式化 pipeline。`isRestoringFromHistory` 标志位防止历史恢复时触发 markDirty。

#### historyStore
管理最多 5 个 SQL 文档（`SqlDocument[]`）。`switchTo(id, flushFn)` 先调用 flushFn 保存当前文档，再切换并返回新文档的 sql。文档编号使用单调递增计数器，localStorage 持久化。

#### themeStore
使用 `useLocalStorage` 持久化主题，`watch` 同步写入 `document.documentElement.setAttribute('data-theme', ...)`。

#### uiStore
使用 `useLocalStorage` 持久化字体大小，`watch` 同步写入 `--editor-font-size` CSS 变量。`leftPanelPct` ref 由 ResizableDivider 写入。

#### InputPanel.vue（最高难度）
`onMounted` 创建 CodeMirror EditorView，`onUnmounted` 销毁。使用 Compartment 热替换主题，watch themeStore.theme 变化。watch formatterStore.sql 检测外部写入（历史恢复），同步到编辑器。

#### PreviewPanel.vue
`computed` 调用 `parseBlocks(formatterStore.outputHtml)`，`collapsed` ref 管理折叠状态，`v-for` 渲染 gutter，`v-html` 渲染代码区。`defineExpose` 暴露 foldAll/unfoldAll/getPlainText。

### 6.3 主题系统

CSS 变量在 `[data-theme='dark']` 和 `[data-theme='light']` 两个选择器下分别定义。themeStore 的 watch 负责切换 `data-theme` 属性。CodeMirror 使用 Compartment 机制热替换主题扩展，无需重建编辑器实例。

### 6.4 技术选型

| 技术 | 版本 | 选型理由 |
|------|------|----------|

## 8. 部署说明

### 8.1 构建

```bash
npm run build
```

产物输出到 `dist/` 目录，包含：
- `index.html`
- `assets/index-[hash].js`（JS bundle）
- `assets/index-[hash].css`（CSS bundle）

### 8.2 部署到静态托管

**Nginx 示例**：
```nginx
server {
    listen 80;
    root /var/www/sql-formatter/dist;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

**GitHub Pages**：将 `dist/` 目录内容推送到 `gh-pages` 分支即可。

**Vercel / Netlify**：直接连接仓库，构建命令 `npm run build`，发布目录 `dist`。

### 8.3 运行时要求

- 现代浏览器（Chrome 90+、Firefox 88+、Safari 14+、Edge 90+）
- 需要 HTTPS 环境以使用 Clipboard API
- 无需服务器，无需数据库，无外部 API 调用

## 9. 已知限制

| 限制 | 说明 |
|------|------|
| 超大 SQL 性能 | 超过 50,000 字符的 SQL 可能出现明显延迟，当前版本不支持 Web Worker 异步处理 |
| 方言支持范围 | 仅支持 PostgreSQL、MySQL、SQLite |
| 复制功能 | 在非 HTTPS 环境下，`navigator.clipboard` 可能不可用 |
| 移动端体验 | 移动端布局为上下堆叠，分隔线拖拽不可用 |
| 历史记录持久化 | ~~历史记录仅保存在内存中，刷新页面后清空~~ v1.3.0 已持久化到 localStorage |
| 逗号位置后处理 | sql-formatter 15.x 已移除 commaPosition 参数，行首逗号由后处理实现 |

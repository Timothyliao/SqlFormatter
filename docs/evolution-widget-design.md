# 进化论小部件 — 重设计方案

> 版本：v2.1 草案  
> 日期：2026-05-18

---

## 设计动机

原有系统将生命体等级与 SQL 语义强绑定（JOIN 数量、CTE 数量等），导致：

- JSON 模式下生命体永远停在 Lv.1
- 彩蛋全部依赖 SQL 关键字触发，换个输入类型就失效
- 生命体是"SQL 复杂度计"，而非真正有生命感的存在

**新方向**：生命体反映的是**用户与工具的交互状态**，和输入内容的语义完全解耦。

---

## 核心理念

> 不问"你的内容有多复杂"，而问"你这个人有多专注"。

生命体是用户使用行为的镜子。无论格式化 SQL、JSON 还是未来任何内容，它都有意义。

---

## 评分模型

```
活跃度分 =
  编辑次数        × 1
  + 专注时长(分钟) × 5
  + 操作多样性     × 10   ← 切换配置/主题/文档，每种各计一次
  + 内容体量档位   × 3    ← 按字符数分档（<100 / <500 / <2000 / 2000+）
```

**波动性**（最近 5 次编辑的内容长度标准差）单独计算，用于决定"纪元"状态，不影响等级分。

---

## 等级体系

共 7 级，三体宇宙风格命名。

| Lv | Emoji | 名称 | 触发条件（活跃度分） |
|----|-------|------|-------------------|
| 1 | 🌑 | 黑暗纪元 | 0 |
| 2 | 🔥 | 恒纪元初期 | 10 |
| 3 | 🌊 | 乱纪元 | 30 |
| 4 | 🏗️ | 文明建设期 | 60 |
| 5 | 🛸 | 技术爆炸 | 100 |
| 6 | 🌌 | 宇宙社会学 | 150 |
| 7 | ☀️ | 二向箔展开 | 200 |

Lv.7 触发特殊视觉效果：widget 缓慢淡出直至完全透明消失，象征二向箔展开后维度归零。鼠标悬停时短暂恢复可见，移开后再次消失。

---

## 纪元状态

叠加在等级之上，影响视觉表现，不影响等级分。

| 状态 | 触发条件 | 视觉表现 |
|------|---------|---------|
| **恒纪元** | 稳定输入，波动性低 | 边框平静发光 |
| **乱纪元** | 短时间大量编辑，波动性高 | 边框快速闪烁 |
| **休眠期** | 空闲超过 2 分钟 | 变灰，emoji 替换为 💤 |
| **复苏** | 休眠后重新输入 | 短暂唤醒动画 + toast 提示 |

---

## 状态机

```
休眠期 ──(开始输入)──▶ 恒纪元 ──(高频编辑，波动大)──▶ 乱纪元
  ▲                      │                               │
  └──(空闲 > 2 分钟)──────┴───────(停止输入)──────────────┘
```

## 彩蛋重设计

全部改为**行为触发**，与输入内容语义无关。

| ID | 名称 | 触发条件 | 效果类型 | 效果内容 |
|----|------|---------|---------|---------|
| `first-contact` | 第一次接触 | 首次使用工具（历史为空） | tagline | "文明的第一步" |
| `reset` | 归零重启 | 清空全部内容 | toast | "归零，宇宙重新开始" |
| `void` | 虚空凝视 | 内容为空但停留超过 1 分钟 | terminal | 凝视深渊对话 |
| `time-traveler` | 时间旅行者 | 撤销/重做累计触发 5 次 | toast | "在时间线上徘徊" |
| `light-seeker` | 寻光者 | 切换主题累计 3 次 | toast | "还没找到合适的光线" |
| `multiverse` | 多元宇宙 | 同时打开 5 个文档 | terminal | 多线程文明对话 |
| `deep-focus` | 深度工作者 | 连续专注 30 分钟 | terminal | 进入深度工作状态 |
| `marathon` | 马拉松 | 累计使用超过 1 小时 | confetti + terminal | 文明长征纪念 |

### 彩蛋 terminal 台词示例

**`void` — 虚空凝视**
```
> SCANNING INPUT...
> INPUT: NULL
> STARING INTO THE VOID...
> THE VOID STARES BACK
> 也许空白本身就是答案
```

**`deep-focus` — 深度工作者**
```
> 专注时长：30 分钟
> 进入深度工作状态
> 外部干扰已屏蔽
> 文明在专注中诞生
```

**`multiverse` — 多元宇宙**
```
> 检测到 5 条平行时间线
> 多元宇宙理论已验证
> 请问哪个才是主宇宙？
```

**`marathon` — 马拉松**
```
> 累计使用：60 分钟
> 你已完成一次文明长征
> 休息一下，宇宙不会跑掉
```

## Tooltip 内容

替换原有的 SQL 细节展示（JOIN ×3 等），改为行为维度：

```
🏗️ 文明建设期
专注时长：12 分钟
操作多样性：3 种
活跃度：47 分
距下一级还差 13 分
```

## 技术决策

| 问题 | 决策 |
|------|------|
| 操作多样性信号来源 | EvolutionWidget 直接使用 `useThemeStore()` / `useHistoryStore()`，store 是全局单例，依赖合理 |
| 撤销/重做事件来源 | 在 EvolutionWidget 内部监听全局键盘事件 `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`，独立计数，零侵入 InputPanel |
| Lv.7 视觉效果 | widget 缓慢淡出至完全透明消失；鼠标悬停时短暂恢复可见，移开后再次消失 |
